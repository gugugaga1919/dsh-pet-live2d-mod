# 桌面端方案

桌宠有两条呈现路径：**页面内**（插件自己渲染，随 DSH 启停）与**桌面上**（一个原生窗口进程，
DSH 关掉她也能站在桌面上）。本文说明桌面端怎么工作、与本 fork 的改动边界、以及排查方式。

## 一、怎么切换

**设置 → 显示位置**：`自动` / `页面内` / `桌面`。

- `自动`：有桌面端就跑桌面端，没有就留在页面里；
- `页面内`：只活在 DSH 页面里；
- `桌面`：拉起原生窗口（页面里那只让位隐藏）。

桌面窗口用的是 **Accessory 激活策略**（不占程序坞、不进 ⌘Tab），窗口在所有桌面空间可见
（切 Space 不会消失）。

## 二、它是怎么工作的

1. **宿主半区**（`lib/desktop.js`）：定位二进制、拉起进程、管生命周期、写状态与日志；
   `lib/display.js` 负责两种显示层之间的切换与"谁在显示"的判定。
2. **二进制来自平台子包**（`optionalDependencies`，按 `os`/`cpu` 自动装或不装）：

   | 平台 | 子包 | npm 状态 |
   | --- | --- | --- |
   | Windows x64 | `dsh-pet-live2d-desktop-win32-x64` | 3.5.0 |
   | macOS arm64（Apple Silicon） | `dsh-pet-live2d-desktop-darwin-arm64` | 3.5.0 |

3. 子包缺失时（`--no-optional`、手动删过 `node_modules`、平台没发布），设置页的
   「显示位置」卡里会给出**「下载桌面端（约 5MB）」**按钮，从 npm registry 拉子包 tarball 解压到本地。
4. 二进制解析顺序：`DSH_PET_DESKTOP_BIN` 环境变量（显式指定，排查用）→ 平台子包 → 自己下载的。

## 三、桌面窗口里跑的是什么（重要）

本机实测（`~/.dsh/pet-desktop.log`）：

```
[shell] 挂载模式：宠物数据与相位都来自 http://127.0.0.1:3081
[shell] 内嵌资源：76 个文件（5.46 MB）
[shell] 宿主已就绪：http://127.0.0.1:56795
[shell] 显示层决定：她在桌面上
```

也就是说：

- **UI 资源是内嵌在二进制里的**（76 个文件 / 5.46MB，编译进 Mach-O/PE），
  **网页端 `lib/client.js` 的补丁不会进入桌面壳**；
- **宠物数据与相位从 DSH 读**（`http://127.0.0.1:<端口>`）：`pet.json`、贴图、物理、动作、表情。

因此本 fork 的改动在桌面端的生效边界是：

| 改动 | 桌面端 | 原因 |
| --- | --- | --- |
| 贴图降采样、物理增益、动作/表情文件、`pet.json`（待机动作文件、表情时长不是它） | ✅ 生效 | 数据来自 DSH |
| 待机微动（程序化）、鼠标追踪修复、气泡重做、设置页签 | ❌ 不生效 | 在 `client.js` 里，桌面壳用内嵌版本 |

> 想让桌面端也带上网页端修复，只能等上游重新构建发布桌面子包（二进制是单文件、
> 资源编译在内，没有"替换某个文件"的口子）。本 fork 的 `DSH_PET_DESKTOP_BIN`
> 只能换二进制，不能换资源。

## 四、排查

| 要看什么 | 位置 |
| --- | --- |
| 当前状态（模式 / PID / 启动时间） | `~/.dsh/pet-desktop.json` |
| 运行日志 | `~/.dsh/pet-desktop.log` |
| 强制指定二进制 | `DSH_PET_DESKTOP_BIN=/path/to/dsh-pet-live2d-desktop` |
| 子包是否装了 | `~/.dsh/profiles/web/node_modules/dsh-pet-live2d-desktop-<平台>` |

常见症状：

- **设置里「桌面端：没在跑」**：二进制不存在（装的时候跳过了 optional 依赖），
  点「下载桌面端」或手动 `npm i dsh-pet-live2d-desktop-darwin-arm64`；
- **点了「桌面」没反应**：看 `pet-desktop.log` 最后一行；macOS 上若报 `EACCES`，
  是二进制没有执行位（`chmod +x`）；
- **页面里那只和桌面窗口同时出现**：显示层判定还没刷新，切一次「页面内 → 桌面」或刷新页面。

## 五、建议

- 想要**完整体验本 fork 的全部改动** → 用「页面内」模式；
- 需要**DSH 关掉也站着** → 用「桌面」模式，接受桌面壳是上游 3.5.0 的行为。
